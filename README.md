# Navigating-the-Capacity-Generalization-Trade-Off-in-Low-Data-EOG-Eye-Writing
Official implementation of "Navigating the Capacity-Generalization Trade-Off in Low-Data EOG Eye-Writing" (BSPC): a family of 1D-CNNs, three evaluation protocols (Subject-Mixed / User-Dependent / LOSO), a structure-constrained character decoder, and embedded-ready models for EOG-based assistive communication.
